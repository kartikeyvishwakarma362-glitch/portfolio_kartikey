Dark neon gaming dashboard inspired portfolio built with plain `HTML`, `CSS`, and `JavaScript`.

## How To Customize

1. **Change profile photo**  
<img src="image/kartikey.jpg" />

2. **Change project images**  
   Replace project images in the `images` folder (example: `images/project-1.jpg`).

3. **Edit text content**  
   Open `index.html` and edit any text marked with comments like `<!-- Edit this text -->`.

4. **Add a new project card**  
   In `index.html`, go to the Projects section and copy one `<article class="project-card ...">` block.  
   You can use the comment: `<!-- COPY THIS CARD TO ADD NEW PROJECT -->`.

5. **Change colors/theme**  
   Open `style.css` and edit CSS variables in `:root` (`--bg`, `--card`, `--primary-purple`, `--neon-blue`, `--cyan`, etc).

6. **Run website**  
   Open `index.html` directly in any browser.
